# ClipStack 📋

光标处弹出的多段剪贴板历史工具 —— 解决"连续复制内容互相顶替"的问题。

## 解决什么问题

传统复制粘贴一次只能存一段内容：复制第二段时，第一段就被顶掉了。想依次搬运 5 段内容，只能"复制→粘贴→切换→复制→粘贴"来回折腾。

**ClipStack 的方式**：先连续复制 5 段（互不顶替），再切到目标位置按 Ctrl+V，从弹窗里逐个选着粘贴。

## 功能

- 📋 后台自动记录每次复制的内容：**文字 / 图片 / 文件**，互不顶替（上限 50 条）
- 🖼️ 图片条目带**缩略图预览**，点缩略图或文字都能粘贴
- 🖱️ 弹窗精确出现在**鼠标光标位置**，按复制顺序排列
- ⚡ 智能粘贴：历史只有 1 条时 Ctrl+V 和原来一样直接粘贴；有 2 条以上才弹窗选择
- 🔢 弹窗内 `Enter` 粘最新一条、数字键 `1~9` 粘第 N 条、点击任意条目即粘贴
- ✂️ 每条右侧 `×` 单独删除，底部「全部清除」一键清空
- 🎵 双击 `Ctrl` 切换功能总开关（开=上行提示音，关=下行提示音）
- 🚀 **首次运行自动注册开机自启**（写 HKCU Run 键，无需管理员权限），弹窗底部「开机自启：开/关」随时切换
- 🛡️ 单实例保护，重复启动不会冲突；模拟粘贴时自动让路，不会死循环

## 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+V` | 单条→直接粘贴；多条→光标处弹窗 |
| `双击 Ctrl` | 开启 / 关闭多条粘贴功能（带提示音） |
| `Enter` / `1~9` / 点击 | 粘贴对应条目 |
| `Esc` | 关闭弹窗不粘贴 |
| `Ctrl+Shift+V` | 备用呼出键（始终弹窗） |

## 下载使用

1. 到 [Releases](../../releases) 下载 `ClipStack_v1.2_win64.zip`
2. 解压到任意文件夹（exe 和两个 wav 音效要放在一起）
3. 双击 `ClipStack.exe` 即可，无需安装、无需 Python
4. 首次运行会自动开启开机自启；不想开机自启就点弹窗底部「开机自启：关」

> 首次运行如被杀毒软件/SmartScreen 拦截，选择"仍要运行"即可（无签名 exe 的常见提示）。

## 运行原理 & 隐私

- 通过 Win32 API 监听剪贴板，所有历史**只存在内存里**，不写磁盘、不上传
- 图片走 `CF_DIB`、文件走 `CF_HDROP`，粘贴出去保留原格式
- 全局键盘钩子仅用于"双击 Ctrl"检测，不做任何按键记录

## 从源码构建

需要 Python 3.10+：

```bash
pip install pillow pyinstaller
python gen_sounds.py          # 生成提示音
python -m PyInstaller --onefile --noconsole --name ClipStack clipstack_win32.py
```

直接跑源码：`python clipstack_win32.py`（或 `pythonw` 静默后台运行）

## 文件说明

```
clipstack_win32.py   主程序（纯 Python + ctypes 调 Win32 API，无 GUI 框架依赖）
gen_sounds.py        提示音生成脚本（改音符/时长后重跑即可换音效）
复制开.wav / 复制关.wav  双击 Ctrl 的开关提示音
```
